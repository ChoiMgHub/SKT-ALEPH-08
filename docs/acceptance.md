가상 인증기의 통과로 갤럭시에서 두 키가 만들어졌다고 적지 않는다. 다른 브라우저나 시크릿 창을 쓰는 것만으로 두 번째 키를 등록한 것이 되지 않는다. 시험용 소프트웨어 키와 사용자의 실기기 키는 분리한다.

추가 등록 무반응 보고 뒤, 최근 인증 제한 오류가 버튼 근처에 표시되지 않는 UI 문제를 재현해 수정했다. 당시 총 19개 테스트 통과. 서버의 5분 제한·소유권 검사·서명 검증은 완화하지 않았다. 사용자 실제 오류 원인은 수정본에서 표시할 안내를 통해 추가 확인한다.

등록된 키 두 개를 확인한 뒤, 기기 창의 계정 이름만으로 로그인 키를 구분하기 어려워 서버 세션 기준 키 이름 표시와 키별 로그인 확인 버튼을 추가했다. 자동 테스트 23개, 격리 workerd 확인 42개 통과. 이후 사용자가 서버 표시로 예비 키 인증과 기본 키 삭제 후 남은 키 인증을 확인했다.

B에서 로그아웃 후 A를 선택했을 때 검증 실패가 보고돼, 계정 지정 로그인에서 현재 유효한 키만 요청하고 challenge도 해당 계정에 묶도록 보완했다. 총 25개 테스트와 격리 workerd 46개 확인 통과. 사용자는 재배포 후 아이디 지정 A 예비 키 로그인 성공과 A/B 목록 분리를 확인했다. 오류 문자열만으로 삭제된 기본 키를 선택했다고 확정하지 않는다.
