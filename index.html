행동:아쉬움에 머물지 않고, 시스템과 소프트웨어가 융합되는 'AI 인프라'로 진로를 정해 SKT ALEPH에 도전함.
결과:취업이라는 절박한 목표를 향해 매일 기술을 흡수하는 명확한 내적 동기와 집중력을 확보함.

2. 절박함에서 나오는 집요한 완주력

행동:부족함을 숨기지 않고 모르는 개념을 AI와 기술 문서를 통해 끝까지 파고들며 즉시 실습으로 메움.
결과:첫 과제에서 마주친 배포 오류와 접근성 기준을 회피하지 않고 끝까지 추적해 100% 완주해 냄.

3. 작은 산출물부터 증명하는 실행 태도

상황:혼자 거창한 프로그램을 만들어본 적이 없어 웹 배포와 Git 관리에 대한 막연한 두려움이 있었음.
행동:AI 코드를 맹신하지 않고 키보드 조작, 명암 대비, 콘솔 에러를 직접 테스트하며 한 단계씩 해결함.
결과:빈 화면에서 시작해 누구나 접속 가능한 실제 배포 웹사이트라는 내 손으로 만든 첫 산출물을 완성함.

학원 PC의 Windows 계정 설정을 바꿀 필요는 없습니다. 갤럭시 Chrome에서 이 HTTPS 사이트를 직접 열고 지문·패턴·PIN으로 패스키 사용을 승인할 수 있습니다.

공개키는 로그인 서명을 검사하는 값이며 비밀번호가 아닙니다. 기기의 개인키나 지문 원본은 이 앱 서버에 보내지 않습니다. 동기화형 패스키는 저장소 제공자의 방식으로 암호화·동기화될 수 있습니다.

두 번째 패스키 추가

같은 계정에 서로 다른 패스키를 등록하세요. 같은 키가 동기화되어 두 기기에 보이는 것은 키 두 개가 아닙니다. 이미 등록됨이 표시되면 다른 지원 저장소·개인 기기를 선택하세요.

버튼을 누른 뒤의 진행 상황과 오류는 바로 위에 표시됩니다. 로그인 후 5분이 지났다면 로그아웃 후 다시 로그인하세요.

패스키 추가·삭제는 로그인 후 5분 안에 가능합니다. 마지막 패스키 삭제는 차단합니다. 모든 패스키에 접근할 수 없게 되면 이 앱에는 계정 복구 기능이 없습니다. 가상 아이디만으로 자료를 넘겨주거나 새 키를 등록해 주지 않습니다.
